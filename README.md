# Learning Clock

An offline tablet app that helps a young child learn to tell the time from analog and digital clocks.

- Requirements: [`features/`](features/) (BDD, Gherkin)
- Time logic: [`src/time.js`](src/time.js)
- Tests: `npm test` (Node 22 or newer, no dependencies). The tests use the `Examples` tables in the feature files.
- Notes for whoever picks this up next: [`HANDOFF.md`](HANDOFF.md)
